The chapter in six stops

One puzzle runs through it: several unknowns, the same number of clues, find the values.

  1. Read the puzzleA table of numbers, times a list of unknowns, gives a list of known totals. That is all Ax = b says.
  2. Skip the obvious routeComputing the inverse looks direct. But every number a computer stores is slightly rounded, and that route lets the rounding do real damage.
  3. Solve trianglesIf the table is a triangle, one line has a single unknown. Solve it, carry the answer down, and the rest fall one by one.
  4. Break any table into trianglesSubtract rows until a triangle remains, and keep the multipliers as a second triangle. Swap rows first, so you never divide by a bad number.
  5. Inverting and multiplying are twinsWhatever speed you can multiply matrices at, you can invert them at the same speed, and the other way round.
  6. Well-behaved tables, and best fitsSome tables never need a swap. They turn up when you fit a curve through noisy measurements.

Three receipts, three unknown prices

Each row of a table of numbers is one clue about the unknowns, and the same multiply-and-add rule reads every row.

Amina, Bo and Chen each bought tea, buns and apples at the same café. The receipts show how many of each they bought, and the total. Nobody wrote down the prices. Three receipts, three unknown prices: can you work them out?

Write the counts as a table. A table of numbers like this is a matrix. Write the prices as a list, and the totals as another list. A list of numbers is a vector. Each receipt is now one line: multiply each count by its price, add them up, and you must hit the total.

Those clues together are a system of linear equations. Mathematicians write the whole set in three symbols: A x = b. It looks short, but it is just the three receipts.

With numbers: Amina's row is 2 teas, 1 bun, 1 apple, total 9. With prices 3, 2 and 1 that gives 2 × 3 + 1 × 2 + 1 × 1 = 9, so her receipt matches.

Try it: press Next and watch your guessed prices get checked against each receipt, one row at a time. Then move the three sliders. The machine jumps to the verdict. Every price is a whole number. Can you make all three receipts match?

What the book says

The process starts with a set of linear equations in n unknowns x1, …, xn. A solution is a set of values that satisfy all of the equations simultaneously. The book treats the case of exactly n equations in n unknowns, and rewrites them as the matrix-vector equation Ax = b, with A = (aij), x = (xi) and b = (bi).

28.1 · solving systems of linear equations

One answer, none, or endless?

Clues with two unknowns are lines on a map, and the answer is the spot where all the lines meet, if such a spot exists.

Take two unknowns, x and y. A clue such as "x + y = 5" is true at many spots, and those spots form a straight line. A second clue gives a second line. The answer has to lie on both, so it is the crossing point.

So the question "how many answers?" is a question about lines. Two lines that cross give one answer. That is the good case, and a matrix that gives it is called nonsingular. Two lines going the same way never cross, or lie on top of each other. That matrix is singular: it gives no answer or endless ones.

Too few clues leave the unknowns free to slide: the system is underdetermined. Too many clues usually can't all be true at once: the system is overdetermined. This chapter solves the one-answer case first, and comes back for "too many clues" at the very end.

Read the maths
n clues, n unknowns, rank(A) = n:
exactly one answer
n
How many unknowns there are.
rank
How many of A's rows really say something new. A row that only repeats others adds nothing.

With numbers: the rows (1, 1) and (2, 2) point the same way, so their rank is 1, less than n = 2: no single crossing point. The rows (1, 1) and (1, −1) have rank 2: one crossing.

Try it: press Next to add one clue at a time. Then drag tilt to 1: the second line turns parallel to the first, and the answer is gone. Set total to 5 as well, and the two lines become one. Finally pick Three clues and hunt for a setting where all three lines meet.

What the book says

If A is nonsingular, it possesses an inverse A−1, and x = A−1b is the solution vector. It is unique: two solutions x and x′ would have Ax = Ax′ = b, and multiplying by A−1 shows x = x′.

The section focuses on nonsingular A or, equivalently, on A whose rank equals the number n of unknowns. If there are fewer equations than unknowns, or more generally if the rank is less than n, the system is underdetermined. It typically has infinitely many solutions, although it may have none at all if the equations are inconsistent. If the equations outnumber the unknowns the system is overdetermined, and there may not exist any solutions.

The book gives no listing for this. The procedure below is this page's own way to tell the cases apart: compare the rank of A with the rank of A and b written side by side.

28.1 · numerical stability

The direct route loses digits

Finding the inverse first looks like the short way, but small rounding errors can grow along it, so in practice equations are solved another way.

Every matrix A that gives one answer has a partner, its inverse. Multiply the partner by b, and out comes x. It works on paper, the way "divide by 2" undoes "times 2". So why not always do that?

Computers keep only so many digits, and each result gets rounded. Those tiny slips are called round-off errors. A calculation is numerically unstable if it lets them grow. Going through the inverse can do that: the inverse can have big numbers, and the last step subtracts big results that nearly cancel. The slips survive, and what is left is mostly slip.

This machine uses a pretend calculator that keeps only 3 digits, and a system picked so the damage shows. Real computers keep far more digits, and the errors are far smaller, but they are the same kind of error. The second route is the chapter's method, which the next machines explain.

Read the maths
x = A⁻¹ b
A⁻¹
The inverse of A: the matrix that undoes A, so A⁻¹ A is the matrix that changes nothing.
x, b
The unknowns and the totals, as before.

With numbers: here A⁻¹ has a row −7, 3. So x₁ = −7 × 17.5 + 3 × 42.5 = −122.5 + 127.5 = 5. Keep 3 digits and that becomes −122 + 128 = 6.

A common mix-up: the inverse is not wrong. On paper it gives the exact answer. Trouble only comes when it is computed with rounded numbers, which is what computers do.

Try it: press Next on Through the inverse and watch x₁ come out wrong. Then pick Through triangles: same system, same calculator, right answer. Now raise digits kept to 4. More digits hide the problem in this tiny example. The book's warning is about what rounding can do over the course of a long computation.

What the book says

Because actual computers have limits to how precisely they can represent floating-point numbers, round-off errors may become amplified over the course of a computation, leading to incorrect results. Such computations are called numerically unstable. The book says it will consider numerical stability only briefly, and refers the reader to the book by Higham.

One option for solving Ax = b is to compute A−1 and multiply b by it. The book's verdict: “This approach suffers in practice from numerical instability.” LUP decomposition is numerically stable and has the further advantage of being faster in practice.

The 3-digit calculator and this 2 by 2 system are this page's own example, picked to show the effect in very few steps. The book gives no such example and no listing for it.

28.1 · overview of LUP decomposition

Trade one hard puzzle for two easy ones

Reorder the clues, split the table into two triangles, then solve the two triangle puzzles one after the other. That is the whole plan.

A full table of numbers is hard to solve, because every unknown is tangled up with every other. But a table shaped like a triangle, with only zeros on one side of the diagonal, is easy. The plan is to turn the one hard table into easy ones.

Three pieces do it. A permutation P puts the rows in a better order. A lower triangle L has 1s on its diagonal and zeros above. An upper triangle U has zeros below its diagonal. The promise is that the reordered A equals L times U. Finding those three is called an LUP decomposition.

Once you have them, A x = b splits in two. First solve L y = Pb, which gives a helper list y. Then solve U x = y, which gives the answer. In this machine the three pieces are handed to you. The next machines show how each step works.

Read the maths

P
Says which row goes where. Multiplying by it only reorders rows.
L

U
Upper triangle.

With numbers: P puts row 3 of A first: 5, 6, 3. And L × U gives the same first row: 1 × 5, 1 × 6, 1 × 3.

Read the maths

y
A helper list that stands for U x. You find it first, then use it as the totals for U.

With numbers: L y = P b gives y = 8, 1.4, 1.5. Then U x = y gives x = −1.4, 2.2, 0.6.

Why it works: L U x is the same as L y, which is P b. And L U is P A. So P A x = P b, which is A x = b with its rows reordered. Reordering clues changes nothing about the answer.

Try it: press Next and follow the book's example to its answer. Then pick A different b and step through again. Notice that P, L and U stay exactly the same: only the two quick solves are redone.

What the book says

The idea is to find three n × n matrices L, U and P such that PA = LU, where L is a unit lower-triangular matrix, U is an upper-triangular matrix, and P is a permutation matrix. Every nonsingular matrix A possesses such a decomposition.

Multiply both sides of Ax = b by P, substitute LU for PA, and define y = Ux. Solve the lower-triangular system Ly = Pb by forward substitution, then the upper-triangular system Ux = y by back substitution. Since P is invertible, A = P−1LU, and that makes Ax = P−1Ly = P−1Pb = b.

The example here is the book's: A has rows (1, 2, 0), (3, 4, 4), (5, 6, 3) and b = (3, 7, 8). The second b in the machine is this page's own. The book states the plan in words and equations; the three-line procedure below writes it down.

28.1 · forward and back substitution

A triangle gives up one unknown at a time

When one line has a single unknown, read it off and carry it into the next line. That line now has a single unknown too.

Picture a row of dominoes. The first line of a lower triangle says y₁ = 8, with nothing else to work out. Push that domino: the second line contains only y₁ and y₂, and y₁ is now known. So y₂ falls. Then y₃.

That is forward substitution: top to bottom, each answer carried down. An upper triangle is the same trick in reverse, starting from its last line and working up. That is back substitution.

There is one small difference. L has 1s on its diagonal, so forward substitution never divides. U has any numbers there, so back substitution divides by them at each step.

Read the maths: forward
yᵢ = b[π[i]] − Σ lᵢⱼ yⱼ
b[π[i]]
The total that belongs to row i after reordering.
Σ lᵢⱼ yⱼ
Add up every earlier y times its number in row i (j runs from 1 to i − 1). These values are known already.

With numbers: y₂ = 3 − 0.2 × 8 = 1.4.

Read the maths: back
xᵢ = (yᵢ − Σ uᵢⱼ xⱼ) / uᵢᵢ
Σ uᵢⱼ xⱼ
Add up every later x times its number in row i (j runs from i + 1 to n). You already found those.
uᵢᵢ
The diagonal number of row i. Divide by it to get xᵢ alone.

With numbers: x₃ = 1.5 / 2.5 = 0.6, then x₂ = (1.4 + 0.6 × 0.6) / 0.8 = 2.2.

Why it is quick: line i uses at most i numbers, so all the lines together use about n × n / 2 of them. For 1,000 unknowns that is half a million small sums. The next machine costs far more, but it is run only once.

Try it: press Next on Forward and watch each answer fly down into the next line. Then pick Back. Move the first total slider to change the puzzle and see every answer change with it.

What the book says

Forward substitution solves the lower-triangular system Ly = Pb in Θ(n2) time, given L, P and b. An array π[1 : n] represents P compactly: π[i] says that row i of P has its 1 in column π[i], so Pb has bπ[i] as its ith element. Since L is unit lower-triangular, the first equation gives y1 = bπ[1] directly, and each later yi follows by substituting the earlier values “forward” into equation i.

Back substitution solves Ux = y in the same way, solving the nth equation first and working backward to the first, also in Θ(n2) time. LUP-SOLVE combines the two.

The book's example has L's rows (1, 0, 0), (0.2, 1, 0), (0.6, 0.5, 1) and U's rows (5, 6, 3), (0, 0.8, −0.6), (0, 0, 2.5), with Pb = (8, 3, 7). It finds y = (8, 1.4, 1.5) and x = (−1.4, 2.2, 0.6).

28.1 · computing an LU decomposition

Subtract rows, and keep the receipts

Subtract rows to clear the numbers under the diagonal. What remains is one triangle, and the amounts you subtracted form the other.

Take any row and subtract a multiple of another row from it. The clues still say the same thing, but you can choose the multiple so a number turns into zero. That move is the whole method. It is called Gaussian elimination.

Start at the top left. That number is the pivot. For each row below, ask how many pivots fit into the number under it. That count is the multiplier. Subtract that many copies of the pivot's row, and a zero appears. Column cleared, the top row is finished. The rest of the table is a smaller table of the same kind, called the Schur complement. So do it all again, one size smaller.

Two things come out at the end. The rows you finished form the upper triangle U. Every multiplier you used, written down in the spot it cleared, forms the lower triangle L. An LU decomposition is just the record of the elimination.

Read the maths
lᵢₖ = aᵢₖ / aₖₖ
aᵢⱼ = aᵢⱼ − lᵢₖ uₖⱼ
k
The round we are in: which pivot we are using.
aₖₖ
The pivot.
lᵢₖ
The multiplier for row i. It goes into L.
aᵢⱼ
A number in row i, updated by the subtraction.
uₖⱼ
A number from the finished row k, now part of U.

With numbers: the pivot is 2 and the number under it is 6, so the multiplier is 6 / 2 = 3. Row 2 then has 13 − 3 × 3 = 4.

Why the multipliers form L: to undo the subtraction you would add those same multiples back. Adding back is exactly what multiplying by L does. So L × U rebuilds A.

Try it: press Next and watch the multipliers collect in L while U fills up row by row. Pick Stored in place to see the same run the way the book's figure draws it. Then drag row 2, column 2 to 9: the next pivot becomes 0, and the method has to stop.

What the book says

To create an LU decomposition, the book uses Gaussian elimination: subtract multiples of the first equation from the others to remove the first variable from them, then do the same with the second equation, until an upper-triangular form remains. This is U. L comprises the row multipliers.

Recursively, A splits into a11, a row wT, a column v and a smaller matrix A′. The (n − 1) × (n − 1) matrix A′ − vwT/a11 is the Schur complement of A with respect to a11. If A is nonsingular so is the Schur complement, so it has an LU decomposition L′U′, and L gets v/a11 and L′ while U gets a11, wT and U′.

The denominators in each step are called pivots, and they occupy the diagonal of U. If a pivot is 0 this method doesn't work, because it divides by 0. Because line 11 is triply nested, LU-DECOMPOSITION runs in Θ(n3) time. A standard optimization stores the significant elements of L and U in place in the matrix A.

28.1 · why pivoting is needed

A bad pivot breaks the method, and a swap fixes it

Dividing by zero stops the method dead, and dividing by a tiny number quietly ruins it. Swapping two rows fixes both.

The method divides by each pivot. So look at what happens when a pivot is a bad number. If it is 0, you can't divide at all. The whole method stops, even though the system may have a perfectly good answer.

A tiny pivot is sneakier, because nothing visibly breaks. Dividing by 0.0001 gives a multiplier of 10,000. Subtracting 10,000 copies of a row swamps the small numbers in the row below, and a calculator that keeps few digits rounds them away. The answer comes out wrong, with no warning.

The fix changes nothing about the puzzle, because the order of the clues doesn't matter. So swap the row with the bad pivot for a row below it that has a bigger number in that column. Swapping rows to get a good pivot is called pivoting.

Read the maths
multiplier = aᵢₖ / pivot
aᵢₖ
The number to clear, in row i under the pivot.
pivot
The number we divide by. A small pivot makes a big multiplier.

With numbers: 1 / 0.0001 = 10,000. But swap the rows and it is 0.0001 / 1 = 0.0001. The same two numbers, and the multiplier is now tiny.

Why a big pivot is safe: choose the largest number in the column, and every multiplier is at most 1. Nothing gets scaled up, so rounding errors have much less to feed on.

Try it: Zero, plain stops at once. Zero, swap rescues the same table. Then run Tiny, plain and Tiny, swap. The tiny runs use a 3-digit calculator. Drag tiny pivot from 0.1 down to 0.00001 and watch the plain answer for x₁ fall apart, while the swapped one stays right.

What the book says

If a11 = 0, the LU method doesn't work, because it divides by 0. It also doesn't work if the upper leftmost entry of the Schur complement is 0, since the next step of the recursion will divide by it.

Using permutations to avoid division by 0, or by small numbers, which can contribute to numerical instability, is called pivoting. Even if the diagonal contains no 0s but does have numbers with small absolute values, “dividing by such numbers can cause numerical instabilities.” Therefore LUP decomposition pivots on entries with the largest absolute values that it can find.

The two small tables and the 3-digit calculator are this page's own examples. The book doesn't include this demonstration or a listing for it. The procedures below contrast elimination that trusts the diagonal with elimination that first picks the largest entry.

28.1 · computing an LUP decomposition

Pick the largest, swap, then subtract

Each round looks down one column, brings its largest number up to the top, and clears everything beneath it. A short list remembers each swap.

This is the full method. Every round has three moves. Look down the current column and find the number with the greatest size, ignoring its sign. Swap its whole row up, so that number becomes the pivot. Then clear the numbers underneath, as before.

The swaps must be remembered, since b has to be reordered the same way later. The book keeps them in a small list called π (the Greek letter pi). Read it like this: π[1] = 3 means "the row now in place 1 came from row 3 of A". This list is P, written the short way.

Only the column below the current round is ever searched. So finished rows stay put, and the multipliers sitting below the diagonal move along with their rows whenever a swap happens.

Read the maths
P[i, π[i]] = 1
π[i]
The original row number now in place i.
P
The same fact as a table: in row i, the 1 sits in column π[i], and everything else is 0.

With numbers: if π = 3, 1, 4, 2, row 1 of P has its 1 in column 3. So row 1 of P A is row 3 of A.

Why this can't divide by 0 when A is nonsingular: if a whole column at or below the diagonal were 0, A would be singular. So there is always a nonzero number to swap up. If there is none, the method reports "singular matrix".

Try it: press Next and watch the rows glide when they swap, with π and P updating beside them. The bars show each column's candidates. Then pick First nonzero, a lazier rule that takes the first usable number. Compare the largest multiplier tile: the book's rule keeps it at 1 or less.

What the book says

Before partitioning the matrix, LUP decomposition moves a nonzero element ak1 from the first column to the (1, 1) position. For the greatest numerical stability it chooses the element with the greatest absolute value. The first column cannot contain only 0s, for then A would be singular. Exchanging row 1 with row k is equivalent to multiplying A by a permutation matrix Q on the left.

The Schur complement is again nonsingular, so it has its own LUP decomposition P′(A′ − vwT/ak1) = L′U′, and the book defines P from P′ and Q. Unlike LU decomposition, both v/ak1 and the Schur complement are multiplied by P′, which is why entire rows are swapped.

The procedure maintains π[i] = j, meaning the ith row of P has a 1 in column j, and computes L and U in place. It runs in Θ(n3) time, the same as LU-DECOMPOSITION, so pivoting costs at most a constant factor in time.

28.2 · a matrix inverse from LUP

The inverse is n small solves

When you really do need the inverse, solve for it one column at a time, using the same two triangles over and over.

Sometimes you do need the inverse itself. Here is a neat way to get it. The inverse X is the matrix with A X = I, where I is the identity matrix: 1s on the diagonal, 0s elsewhere, the matrix that changes nothing.

Read that one column at a time. A times the first column of X must give the first column of I. That is just A x = b, with b = 1, 0, 0. The second column is another A x = b, and so is the third. So finding an inverse is n ordinary solves.

And you already know that the slow part, splitting A into triangles, never looks at b. Do it once, then each column costs only the two quick triangle solves.

Read the maths
A Xᵢ = eᵢ
Xᵢ
Column i of the inverse, which we are looking for.
eᵢ
Column i of the identity matrix: all 0s, with a 1 in place i.

With numbers: for the book's A, solving A X₁ = (1, 0, 0) gives X₁ = (−1.2, 1.1, −0.2). Check the first row of A: 1 × −1.2 + 2 × 1.1 + 0 × −0.2 = 1.

Try it: press Next and watch X fill in, one column per solve. Then pick Reuse or redo? and drag n to compare one split shared by every column with a fresh split for each.

What the book says

In practice you are better off solving linear systems with numerically stable techniques such as LUP decomposition, but sometimes you really do need to compute a matrix inverse. Once you have the LUP decomposition of A, you can solve, in Θ(kn2) time, k versions of Ax = b that differ only in the vector b.

Think of AX = In as a set of n distinct equations of the form Ax = b: AXi = ei. You compute each of the n columns in Θ(n2) time, so all of X in Θ(n3). Since the decomposition also takes Θ(n3), you can compute the inverse of A in Θ(n3) time.

28.2 · matrix multiplication and matrix inversion

Multiply using nothing but an inverter

Hide two matrices inside one bigger matrix, invert it, and their product is sitting in the corner. So multiplying can't be harder than inverting.

Here is a surprising fact: inverting and multiplying are equally hard. Any fast method for one gives a fast method for the other. This machine shows the first half. Suppose you own a very fast machine that inverts matrices. Can you make it multiply?

You can, with a trick. To multiply A by B, build a larger matrix D. It has identity matrices on its diagonal, A and B just above them, and zeros everywhere else. Invert D. The product A B appears in D⁻¹'s top right corner.

Read the maths
D = (I A 0; 0 I B; 0 0 I)
D⁻¹ = (I −A AB; 0 I −B; 0 0 I)
I
An identity matrix the same size as A and B.
0
A block of zeros of that size.
;
Separates the three block rows.

With numbers: with A = 2 and B = 3, D has rows (1, 2, 0), (0, 1, 3), (0, 0, 1). Its inverse has rows (1, −2, 6), (0, 1, −3), (0, 0, 1). The corner holds 6 = 2 × 3.

Why the product appears: D links row 1 to row 2 through A, and row 2 to row 3 through B. To undo the link from row 3 back to row 1 takes both hops, one after the other, so A and B get multiplied.

Is it cheating that D is bigger? D has 3n rows rather than n. But the book assumes that tripling n only multiplies the inverter's running time by a constant. Asymptotically, that doesn't count.

Try it: press Next to build D block by block, invert it, then read the corner. Move the a and b sliders and the corner follows. Pick 2 by 2 blocks to see that it works for real matrices too, not only for single numbers.

What the book says

The book proves that matrix inversion is equivalent to matrix multiplication: if M(n) is the time to multiply two n × n matrices, a nonsingular matrix can be inverted in O(M(n)) time, and if I(n) is the time to invert, two matrices can be multiplied in O(I(n)) time.

Theorem 28.1 (Multiplication is no harder than inversion). If an n × n matrix can be inverted in I(n) time, where I(n) = Ω(n2) and I(3n) = O(I(n)), then two matrices can be multiplied in O(I(n)) time. The proof takes the 3n × 3n matrix D above, whose inverse holds AB in its upper right n × n submatrix.

Constructing D takes Θ(n2) time, which is O(I(n)), and inverting it takes O(I(3n)) = O(I(n)). The regularity condition holds whenever I(n) = Θ(nc lgd n) for constants c > 0 and d ≥ 0. The book states the method in its proof; the procedure below writes it down. The numbers in the machine are this page's own.

28.2 · matrix multiplication and matrix inversion

Invert using a handful of multiplications

Cut the matrix into four blocks. Inverting two half-size blocks and doing four multiplications is enough, so inverting can't be harder than multiplying.

Now the other way round. Suppose you own a very fast multiplier. Cut A into four blocks, B, C, its mirror image Cᵀ, and D. Cᵀ is the transpose of C: its rows and columns swapped.

The recipe needs two inversions of half-size blocks, which it does the same way, by recursion. Everything else is multiplications, additions and flips. Each half gets cut again until only single numbers are left. Most of the time goes on those four multiplications at the top.

The recipe needs A to be special: symmetric, the same on both sides of the diagonal, and positive-definite, which section 28.3 explains. That guarantees the two inverses exist. For any other invertible A there is a neat way out, shown in the second mode: Aᵀ A is always special, so invert that, then multiply once more by Aᵀ.

Read the maths

M(n)

O(n²)
The cheap jobs: copying blocks, adding, flipping.

With numbers: for n = 4 that is 2 inversions and 4 multiplications of 2 × 2 blocks. Solving this recurrence gives I(n) = O(M(n)).

Why this matters: together with the last machine it means the two jobs are twins. Find a faster way to multiply matrices, such as Strassen's, and you have automatically found a faster way to invert them.

Try it: press Next to walk through the book's 11 steps on a 4 × 4 matrix. The tiles show only what the current step uses. Watch the tally: exactly 2 inversions and 4 multiplications. Then pick Any matrix.

What the book says

Theorem 28.2 (Inversion is no harder than multiplication). If M(n) = Ω(n2), M(n + k) = O(M(n)) for 0 ≤ k ≤ n, and M(n/2) ≤ cM(n) for some constant c < 1/2, then the inverse of any real nonsingular matrix can be computed in O(M(n)) time.

For symmetric positive-definite A and n an exact power of 2, the book splits A into B, CT, C, D, and sets S = D − CB−1CT. The 11 steps invert B and S recursively and do four multiplications, giving I(n) ≤ 2I(n/2) + 4M(n/2) + O(n2) = O(M(n)), by case 3 of the master theorem.

For any nonsingular A, the matrix ATA is symmetric and positive-definite, and A−1 = (ATA)−1AT. If n is not a power of 2, pad A with an identity block Ik and take the first n rows and columns of the result.

You can use Strassen's algorithm to invert a matrix; the chapter notes say he showed an n × n matrix can be inverted in O(nlg 7) time. Solving Ax = b through ATA is theoretically correct, but in practice LUP-DECOMPOSITION works much better: it needs fewer arithmetic operations by a constant factor and has somewhat better numerical properties. 28.3 · symmetric positive-definite matrices

A bowl with no way down

Some matrices behave like a smooth bowl: whichever way you walk from the bottom, you go up. These are the well-behaved ones.

Take a 2 × 2 matrix A and any list x of two numbers, not both zero. There is a recipe that turns them into one single number, a score. Multiply each pair of entries xi and xj by the number in row i, column j, and add up. For a matrix A, that score is written xᵀAx.

Think of x as a direction you walk in from the centre of a floor, and of the score as the height of the floor one step that way. If every direction gives a score above zero, the floor is a bowl: every path leads up. A matrix like that is positive-definite. If it also mirrors across its diagonal, it is symmetric positive-definite.

If some direction scores below zero, the floor has a downhill path, and the shape is a saddle rather than a bowl. And if A were singular, it would turn some x into all zeros, so that x would score exactly 0: a flat path. A bowl has no flat path, so a positive-definite matrix is always nonsingular.

Read the maths
A = Aᵀ, and xᵀ A x > 0 for every x ≠ 0
A = Aᵀ
A is symmetric: flip it across the diagonal and nothing changes.
xᵀ A x
The score. Multiply A by the list x, then multiply that result by x again and add up.
x ≠ 0
Any list except all zeros, which would score 0 for every matrix.

With numbers: take A with rows (2, 1) and (1, 2), and x = (1, −1). A x = (1, −1). Then x times that is 1 × 1 + (−1) × (−1) = 2, above zero.

A common mix-up: positive numbers don't make a matrix positive-definite. The rows (1, 3) and (3, 1) hold only positive numbers, but x = (1, −1) scores −4. And a matrix with some negative numbers can still be positive-definite.

Try it: press Next and test directions one at a time. Each test draws one slice through the floor. Then drag b slowly up to 2: the lowest slice flattens out. Past that, the floor bends downhill and the bars cross below zero. Watch pivot 2 on its tile turn bad at the same moment.

What the book says

An n × n matrix A is symmetric positive-definite if A = AT (A is symmetric) and xTAx > 0 for all n-vectors x ≠ 0 (A is positive-definite). Such matrices are nonsingular, and an LU decomposition on them will not divide by 0.

Lemma 28.3: any positive-definite matrix is nonsingular. If A were singular, there would be a nonzero x with Ax = 0. Hence xTAx = 0, and A cannot be positive-definite.

The bowl is this page's own picture, and the test directions and numbers are its own. The book gives no procedure for computing the score; the one below writes out the definition. Testing a few directions can show a matrix fails, but can't by itself show it passes: the “lowest direction” in the machine comes from solving exactly for the 2 × 2 case.

28.3 · no pivoting needed

The leftover table stays a bowl

Each round leaves a smaller table that is still a bowl, and a bowl's corner is always positive. So you never divide by zero.

Remember what went wrong with plain LU: a pivot of zero. With a symmetric positive-definite matrix that can't happen. Here is why, in two short facts.

Fact one: the top left corner is positive. Walk in direction x = (1, 0, 0, …). The score works out to just that corner number. A bowl's scores are all above zero, so the corner is too. The first pivot is safe.

Fact two: the leftover is still a bowl. After one round, the smaller table that remains, the Schur complement, is again symmetric positive-definite. So fact one applies to it, and its corner, the next pivot, is safe too. And so on, all the way down. The same is true of each top left square of A, called a leading submatrix.

Read the maths
a₁₁ = e₁ᵀ A e₁ > 0
e₁
The direction (1, 0, 0, …), which is not all zeros.
a₁₁
The top left number: the first pivot.

With numbers: the first pivot here is 4. The next table has rows (4, 4) and (4, 13). It still mirrors, and its corner, 4, is the next pivot.

Symmetric alone isn't enough. The second and third modes are symmetric too. But each has a direction with a score that isn't positive, and the elimination shows it: one gets a pivot of 0, the other a negative pivot.

Try it: press Next and watch each leftover table stay mirrored, with a positive corner. Then pick Pivot 0 and Pivot below 0. The method fails in the first, and in the second it gives away that A was never a bowl.

What the book says

The kth leading submatrix Ak of A is the intersection of its first k rows and first k columns. Lemma 28.4: if A is symmetric positive-definite, every leading submatrix is too. For a contradiction, pad a bad vector xk with 0s, and it would be bad for A as well.

Lemma 28.5 (Schur complement lemma): the Schur complement S = C − BAk−1BT of A with respect to Ak is symmetric and positive-definite. The proof completes the square, then picks y to cancel the first term, so that zTSz = xTAx > 0.

Corollary 28.6: LU decomposition of a symmetric positive-definite matrix never causes a division by 0. In fact every pivot is strictly positive. The first pivot is a11 = e1TAe1, and Lemma 28.5 finishes the job by induction.

28.3 · least-squares approximation

The curve that misses by the least

When measurements are noisy, no simple curve goes through them all. So choose the curve whose misses, once squared and added up, are smallest.

You measure something five times, and each reading has a small error. You want a simple rule that predicts the trend. You have more clues (five readings) than unknowns (a few numbers in the rule), so this is the overdetermined case from the start of the chapter: usually no exact answer exists.

So measure how badly a curve fits. For each point, take the gap between the reading and the curve, drawn here as a vertical line. Square each gap, so small gaps count little and big ones count a lot, then add them up. The curve with the smallest total is the least-squares fit.

Be careful with too much freedom. Give the curve as many unknowns as there are points and it can pass through all of them, for a total of zero. But it fits the noise along with the data, and swings wildly between the points. A simpler curve usually predicts new readings better.

What the book says

You are given m data points (xi, yi), where the yi are subject to measurement errors. You want a function F with small approximation errors ηi = F(xi) − yi. F has the form of a linearly weighted sum of basis functions fj, and a common choice fj(x) = xj−1 makes it a polynomial of degree n − 1.

By choosing n = m, you can calculate each yi exactly. Such a polynomial “fits the noise” as well as the data, and generally gives poor results when used to predict y for previously unseen values of x. It is usually better to choose n significantly smaller than m.

Too many clues become just the right number

Multiply both sides by the flipped table. Too many clues then collapse into just enough, and the result is a bowl the earlier method solves.

Write the fit as a matrix. Each point gets a row, and the row holds the values 1, x and x² at that point. Multiply this table A by the unknown numbers c, and you get the curve's predictions. We want A c to come as close to y as it can. There are 5 clues and 3 unknowns, so it is too tall to solve as it stands.

Calculus finds where the total of squared gaps is lowest, and the result is simple to state. Multiply both sides by the transpose Aᵀ. Now Aᵀ A is square, 3 × 3, with one row per unknown. That single equation is called the normal equation.

Here the last few machines pay off. If A's columns aren't redundant, Aᵀ A is symmetric positive-definite. So LU needs no swaps, and the forward and back substitution you already know finish the job.

Read the maths

A
One row per point, one column per basis function: here 1, x and x².

The coefficients we want.
y
The readings.

With numbers: the first row of the normal equation is 5c₁ + 10c₂ + 40c₃ = 7. Those are the number of points, the sum of the x values, the sum of their squares, and the sum of the readings.

Read the maths

A⁺
The pseudoinverse of A. It acts like an inverse for a table that isn't square.

With numbers: the first row of the book's A⁺ is 0.5, 0.3, 0.2, 0.1, −0.1. Times y, that is 0.5 × 2 + 0.3 × 1 + 0.2 × 1 + 0.1 × 0 − 0.1 × 3 = 1.2.

What the book says

Let A be the matrix of basis-function values, aij = fj(xi), so that Ac is the m-vector of predicted values for y, and η = Ac − y is the vector of errors. To minimize ‖η‖, differentiate ‖η‖2 with respect to each ck and set the result to 0. This gives ATAc = ATy, which in statistics is called the normal equation.

ATA is symmetric, and if A has full column rank it is positive-definite as well. So (ATA)−1 exists, and c = A+y with A+ = (ATA)−1AT, the pseudoinverse. As a practical matter, you would typically solve by multiplying y by AT and then finding an LU decomposition of ATA.

From five points to three numbers

The chapter on one page

The key ideas, in order.

Ax = b is a stack of clues

Each row of A, times the unknowns, must hit its total. Nonsingular A means exactly one answer. Too few or too many clues can mean none or endless.

Don't solve through the inverse

On paper it works. With rounded numbers it suffers from numerical instability, and it is slower in practice than LUP.

Triangles are easy

Forward and back substitution solve one unknown per line, in Θ(n²) time.

Elimination builds the triangles

Subtract rows to get U, and keep the multipliers as L. Its cost is Θ(n³), and it never looks at b.

Pivoting makes it safe

Swap the largest number in the column up to be the pivot. Then there's no division by 0, every multiplier is at most 1, and P records the swaps.

Inverting and multiplying are twins

Each can be done with the other at the same asymptotic cost, so a faster multiplier means a faster inverter.

Bowls need no pivoting

For a symmetric positive-definite matrix, every pivot is positive, because each leftover table is a bowl too.

Best fit is a normal equation

AᵀA c = Aᵀy turns too many noisy clues into a square bowl that LU solves. The result minimises the total of squared errors.

Words to know

The book's words from this chapter, in plain language.

matrix
A table of numbers, in rows and columns.
vector
A list of numbers. Written as one column, it is a matrix with a single column.
system of linear equations
Several equations about the same unknowns, each one a sum of number-times-unknown. A solution makes all of them true at once.
nonsingular
A square matrix with an inverse. Its system Ax = b has exactly one answer, whatever b is.
singular
A square matrix with no inverse. Its rows don't pin down all the unknowns, so Ax = b has no answer or endless answers.
rank
How many of a matrix's rows really say something new.
underdetermined
A system whose rank is below the number of unknowns, for example too few equations. It usually has endless answers.
overdetermined
A system with more equations than unknowns. There may be no exact answer at all.
inverse
The matrix A⁻¹ that undoes A, so that A⁻¹A is the identity matrix.
round-off errors
The tiny slips made because a computer keeps only so many digits of each number.
numerically unstable
A calculation is numerically unstable if it lets round-off errors grow until the result is wrong.
triangle
A square matrix with only zeros on one side of its diagonal. Lower-triangular has zeros above the diagonal; upper-triangular has zeros below.
permutation
A reordering. A permutation matrix P reorders rows; the book stores it as an array π, where π[i] names the row that moves into position i.
LUP decomposition
Three matrices with P A = L U: a permutation P, a lower triangle L with 1s on its diagonal, and an upper triangle U.
forward substitution
Solving a lower-triangular system from the top line down, carrying each answer into the lines below.
back substitution
Solving an upper-triangular system from the bottom line up, carrying each answer into the lines above.
Gaussian elimination
Clearing a column by subtracting multiples of one row from the rows below, then doing the same on the smaller table that remains.
pivot / pivots
The number on the diagonal that each round divides by. Pivots end up on the diagonal of U.
multiplier / multipliers
How many copies of the pivot's row to subtract from a lower row, so the number under the pivot becomes 0. Multipliers end up in L.
Schur complement
The smaller table left over after one round of elimination, once the top row and the left column are set aside.
LU decomposition
Writing A as L × U: a lower triangle with 1s on its diagonal, times an upper triangle.
pivoting
Swapping rows to bring a good number into the pivot position, so you never divide by 0 or by something tiny.
identity matrix
A square matrix with 1s on its diagonal and 0s elsewhere. Multiplying by it changes nothing. Written I.
transpose
A matrix with its rows and columns swapped. The transpose of A is written Aᵀ.
symmetric
A matrix that equals its own transpose: it reads the same on both sides of the diagonal.
positive-definite
A matrix A with xᵀAx above zero for every list x except all zeros. Picture a bowl: every direction leads up.
leading submatrix
The top left square of a matrix, made of its first k rows and first k columns.
least-squares
Choosing the curve whose gaps from the data points, squared and added up, make the smallest total.
fits the noise
A curve so flexible it follows the measurement errors as well as the true pattern, so it predicts new readings badly.
basis functions
The simple building blocks a fitted curve is a weighted sum of, such as 1, x and x².
normal equation
Aᵀ A c = Aᵀ y: the square system whose solution c is the least-squares fit.
pseudoinverse
The matrix A⁺ = (Aᵀ A)⁻¹ Aᵀ. It plays the part of an inverse for a table that has more rows than columns.
